# CHANGES — 2026-07-16

## Free Delivery Flag on Product Variants

Added a `free_delivery` boolean column to `product_variants`. When a variant is
marked `free_delivery = true`, it is excluded from the weight-based delivery
charge calculation. If the entire cart consists of free-delivery variants, the
delivery charge is ₹0.

### Database

- **Migration:** `docs/db/migrations/006_free_delivery_variant.sql`
  ```sql
  ALTER TABLE public.product_variants
  ADD COLUMN free_delivery boolean NOT NULL DEFAULT false;
  ```
- All existing variants default to `false` (no behaviour change until toggled).
- **No RPC changes required** — `place_order` accepts delivery charge from the
  client; the calculation happens in the client/admin before calling the RPC.

### Behaviour Summary

| Cart composition | Delivery charge |
|-----------------|----------------|
| All free-delivery variants | ₹0 |
| Mix of free + non-free variants | Weight-based (only non-free items contribute weight) |
| All non-free variants | Unchanged (full weight-based calculation) |
